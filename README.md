# Daniela Victoria Marín — sitio web personal

Sitio web estático, responsive y sin dependencias de compilación. Está construido con HTML, CSS y JavaScript vanilla.

## Archivos
- `index.html`: estructura y contenido.
- `styles.css`: estilos, paleta, responsive y animaciones.
- `script.js`: menú móvil, animaciones de entrada, barra de progreso y botón para copiar el correo.

## Vista previa local
1. Descomprime el paquete.
2. Abre `index.html` en un navegador. Para una vista previa más fiel, sirve la carpeta con cualquier servidor estático local.

## Publicación
Puedes desplegar la carpeta directamente en cualquier hosting estático (Netlify, Vercel, GitHub Pages, cPanel o servidor propio). No requiere backend ni proceso de build. Asegúrate de publicar los tres archivos en la misma carpeta.

## Antes de publicar
- Confirma que los correos y el teléfono sean los canales que quieres hacer públicos.
- Añade una fotografía profesional si deseas reemplazar la composición gráfica de portada.
- Revisa que los enlaces externos a las publicaciones sigan activos.
- Si vas a usar dominio propio, configura HTTPS y los metadatos sociales (Open Graph) que correspondan.

## Privacidad y contenido
La dirección residencial y los datos de las referencias incluidos en la hoja de vida no se publicaron en este sitio. El contenido se limitó a la información profesional y académica suministrada. No se añadieron fechas de empleo ni credenciales que no aparecieran en el documento.
